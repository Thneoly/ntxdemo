🚀 快速启动
═══════════════════════════════════════════════════════════════════════════════

1. 编译所有组件：
   $ ./plugins/scheduler/scripts/build-echo.sh

2. 建立网络拓扑：
   $ sudo ip link add veth1 type veth peer name veth2
   $ sudo ip netns add ns1 && sudo ip netns add ns2
   $ sudo ip link set veth1 netns ns1 && sudo ip link set veth2 netns ns2

3. 启动 Server（终端 1）：
   $ sudo ./target/debug/Ntx --mode server --iface veth1 \
     --component ./plugins/scheduler/wac/echo-server.wasm

4. 启动 Client（终端 2）：
   $ sudo ./target/debug/Ntx --mode client --iface veth2 \
     --server-ip 10.0.0.1 --count 100 --pps 50 \
     --component ./plugins/scheduler/wac/echo-client.wasm
